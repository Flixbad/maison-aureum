# Contribuer

## Principes

- Garder le ton éditorial, jamais commercial criard.
- Ne pas ajouter de dépendance sans nécessité.
- Les contenus marketing vivent dans `lib/data.ts`.
- Les visuels vont dans `public/images` et `assets`.

## Workflow

1. Créer une branche `feat/` ou `fix/`.
2. `npm run lint` puis `npm run build`.
3. Ouvrir une pull request claire.
